# Documentation Status Model

Use these labels consistently:

- `VERIFIED-IMPLEMENTED` — observed in code/runtime and verified.
- `IMPLEMENTED-NOT-YET-VERIFIED` — code exists but runtime/test verification incomplete.
- `PARTIAL` — some of the intended behaviour exists.
- `PLANNED` — approved direction, not implemented.
- `DEFERRED` — intentionally postponed.
- `BLOCKED` — cannot proceed until a named dependency/decision is resolved.
- `DEPRECATED` — retained only for compatibility/history and not the active path.
- `UNKNOWN` — evidence not yet sufficient.

Avoid generic words such as "done" where verification status matters.
